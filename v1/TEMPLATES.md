目前使用的是第一、二、三版「完整版型」交換，請參閱 [完整主題契約](../THEMES.md)。

## 使用

右上角「更換模板」→ 選擇 →「套用模板」。桌機與手機都有入口。
「還原墨綠預設」立即回復第一版並刪除這個 demo 的外觀偏好。
關閉視窗或按 Escape 不會套用尚未確認的選擇。

目前三款：墨綠精品會所（預設）、深海藍經典、暖白典藏。
這些是同一個會所版型的三個主題，不是另外兩版獨立 demo 的完整移植。

## 結構／替換契約

- `index.html`：共用版面與模板入口。
- `app.js`：既有示意功能與內容；模板切換不重新載入此檔、不重設頁內活動狀態。
- `styles.css`：第一版原始版面，保留不變，無 JavaScript 也顯示墨綠。
- `themes.css`：集中配色、字體、圓角、圖片濾鏡／遮罩及元件外觀。
- `templates.js`：模板清單、固定識別碼、瀏覽器工具列色及白名單驗證。
- `template-picker.js`：獨立切換介面；不存取會員、付款或活動資料。

新增模板：

1. 在 `templates.js` 的 definitions 加入唯一、固定的 `id`、name、description、color。
2. 在 `themes.css` 加入完整 `:root[data-template="固定id"]` 區塊。以 navy 的 token 清單為契約，逐項設定；不要依賴上一個模板的值。
3. 加入對應 `[data-template-option="固定id"]` 的三個預覽色。
4. 檢查標題、文字對比、按鈕與輸入框、所有彈窗、手機排版、鍵盤操作及切回墨綠。

模板只接受已發布的固定識別碼；不能從網址、儲存空間或匯入文字執行程式、載入外部樣式或注入 HTML。
不需要更動既有功能檔，之後也可把整層模板機制接到正式網站的共用版面。

## 儲存與正式環境邊界

只在目前瀏覽器 localStorage 的 `north-lions.demo.lounge-template.v1` 儲存
`{"version":1,"template":"clubhouse"}` 這類外觀設定。跨裝置不會同步；儲存受限時仍可暫時切換，介面會提示。
無分析追蹤，不清除其他網站儲存，不保存或傳送表單與業務資料。
正式網站的全會預設模板、管理員權限與跨裝置同步不屬於此靜態 demo，需另外接入既有正式流程。
